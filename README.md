# **Subscription Management Backend (Razorpay Integration)**

This is a **Node.js backend API** for managing subscriptions, currently supporting **Razorpay** as the payment gateway. It is built with **Express**, and database management is handled using **Drizzle ORM** with PostgreSQL.

---

## 🚀 **Features**

- Subscription creation and management using **Razorpay**.
- Secure API endpoints with **helmet** and **cors**.
- Input validation using **express-validator**.
- Database migrations and schema management with **Drizzle ORM**.
- Easy development and debugging with **nodemon** and **morgan**.

---

## 🛠 **Tech Stack**

- **Backend Framework**: `Node.js` with `Express`
- **Payment Gateway**: `Razorpay`
- **Database**: `PostgreSQL`
- **ORM**: `Drizzle ORM`
- **Security**: `helmet`, `cors`
- **Environment Management**: `dotenv`
